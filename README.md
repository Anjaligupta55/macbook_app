# MacBook Pro Showcase

![MacBook Pro Showcase Banner](macbook_landing_banner_1778850536657.png)

A high-fidelity, Apple-inspired landing page for the MacBook Pro, built with **Next.js 15**, **Tailwind CSS 4**, and **Framer Motion**. This project features cinematic scroll animations, interactive 3D-like components, and a premium design aesthetic that mirrors the official Apple experience.

## ✨ Features

- **Cinematic Hero Section**: A stunning entrance with smooth animations and bold typography.
- **Scroll-Driven Storytelling**: Immersive scroll animations that reveal the MacBook's features as you explore.
- **M3 Deep Dive**: Interactive sections detailing the performance of the M3, M3 Pro, and M3 Max chips.
- **Performance Benchmarks**: Visualized data for memory bandwidth, battery life, and processing power.
- **Liquid Retina XDR Showcase**: A dedicated section highlighting the industry-leading display technology.
- **Interactive Color Stage**: Real-time visualization of different finish options.
- **Responsive & Performant**: Fully optimized for all device sizes with a focus on smooth transitions and fast load times.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [React Spring](https://www.react-spring.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typeface**: Geist & Apple-inspired typography

## 🚀 Getting Started

### Prerequisites

- Node.js 20.x or later
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Anjaligupta55/macbook_app.git
   cd macbook_app
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application.
